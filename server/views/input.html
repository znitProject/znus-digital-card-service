잘 보여주세요.

회사 이메일로 본인 확인을 마치면, ZNUS 디지털 명함에 필요한 정보와 미디어를 한 번에 등록할 수 있습니다.

1
본인 확인회사 이메일 인증
2
프로필 작성정보와 업무 입력
3
공개명함 저장 완료

시작하기

회사 이메일로 인증번호를 받아주세요.

STEP 01

인증번호는 등록된 회사 이메일로 발송됩니다.

별도 회원가입이나 비밀번호는 필요하지 않습니다. 입력한 정보는 디지털 명함 운영 목적으로만 사용됩니다.

프로필 작성

명함에 표시할 정보를 정확히 입력해주세요.

STEP 02

카드 배경 미디어

공개 명함은 아래 5개 페이지를 순서대로 보여줍니다. 각 페이지의 용도를 확인하고, 페이지마다 배경 이미지 또는 영상을 하나씩 선택해 주세요. 입력하지 않은 페이지는 기본 디자인 배경을 사용합니다.

페이지별 배경 미디어는 파일을 선택한 페이지만 새 파일로 교체합니다. 선택하지 않은 페이지의 기존 배경은 유지됩니다.
