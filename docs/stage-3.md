# 3단계: 미디어 처리

- 프로필 사진 또는 영상 한 개는 신규 제출 시 필수이며, 다른 카드 배경은 선택입니다. 재제출 시 미첨부 파일은 유지합니다.
- 이미지·MP4 형식과 크기, 영상 길이·해상도를 검증합니다.
- 현재 파일은 직원별 Drive 자산 폴더에 정리합니다. 새 파일 처리가 모두 성공한 뒤 Sheets를 갱신하며, 실패 복구를 위해 이전 파일은 자동 삭제하지 않습니다.
- 신규 배경 미첨부는 기본값, 재제출 시 미첨부는 현재 배경 유지입니다.
- 로딩·재생 실패 시 기본 배경 위에 명함 정보를 표시합니다.

관련 코드: `apps-script/admin-bound/MediaProcessing.gs`, `web/card-service.js`.

기본 영상 원본은 `cardDesign/명함_디자인/assets/`의 `role.mp4`, `contact.mp4`, `web.mp4`, `links.mp4`입니다. Google 연동에서는 이 네 파일을 Drive 공통 폴더에 두고 관리자 프로젝트에서 `connectDefaultBackgroundFolder('폴더 ID')`를 실행합니다. CompanySettings에 기본 영상 ID를 저장하고 공개 프로젝트가 읽습니다. 기본 영상은 직원 업로드와 별도로 관리합니다.

배경 미첨부 신규 직원은 기본 영상을 재생합니다. 재제출 미첨부는 기존 배경을 유지하고, 기본 디자인 복원을 선택하면 기본 영상을 재생합니다. 직원 이미지·영상 로딩 실패 시에도 기본 영상으로 전환합니다.

확인: 실제 Google 환경에서 프로필·기본 배경·업로드 이미지·MP4 표시.
